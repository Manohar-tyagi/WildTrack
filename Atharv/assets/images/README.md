# WILD TRACK images

Drop royalty-free images here following the file names below. The site uses onerror fallbacks, so missing images won't break the UI.

## Folders
- hero/ — hero backgrounds
- animals/ — animal portraits (tiger-1.webp, elephant-1.webp, ...)
- habitats/ — forest/canopy
- rangers/ — rangers with devices
- usecases/ — uc-1.webp ... uc-8.webp
- news/ — news-1.webp ... news-6.webp
- events/ — ev-1.webp ... ev-4.webp
- icons/ — hardware icons
- team/ — avatars (or use initials)

## Suggested search keywords
- hero/tiger-forest.webp: "tiger forest india cinematic" (Unsplash/Pexels)
- hero/forest-canopy.webp: "forest canopy drone aerial"
- animals/*: species name + "wildlife portrait"
- rangers/ranger-device.webp: "forest ranger radio handheld"
- usecases/uc-*.webp: conservation, anti-poaching, habitat
- news/news-*.webp: wildlife news
- events/ev-*.webp: conservation event

## Specs
- WebP, max 1920px wide, <=250KB each.
- Provide width/height and alt text (already in markup).
- Credit lines in footer/About Credits section.
